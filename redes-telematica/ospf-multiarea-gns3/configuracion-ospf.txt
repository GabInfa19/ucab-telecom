TOPOLOGÍA REAL DEL GRUPO:
  R1 - Central      → IR  → Área 1
  R2 - Ala_Este     → ABR → Áreas 1 y 2  (R4 y R5 cuelgan de R2)
  R3 - Ala_Oeste    → ABR → Áreas 0 y 1  (R6 y R7 cuelgan de R3)
  R4 - N_Este       → IR  → Área 2
  R5 - S_Este       → IR  → Área 2
  R6 - N_Oeste      → BR  → Área 0
  R7 - S_Oeste      → BR  → Área 0
  R8 - ISP/ASBR     → ASBR→ Área 0 + Externa

VIRTUAL-LINK: entre R2 (2.2.2.2) y R3 (3.3.3.3) pasando por Área 1
  → R2 lo necesita para conectar el Área 2 al backbone (Área 0)
  → R3 es el punto de tránsito porque toca el Área 0 directamente

INTERFACES REALES (c3725 con WIC-2T):
  Seriales: Se0/0, Se0/1  (WIC-2T en slot wic0)
  FastEth:  f0/0, f0/1    (GT96100-FE en slot0)
  FastEth:  f1/0           (NM-1FE-TX en slot1, solo en R1,R4,R5,R6,R7)

PREREQUISITO: rutas estáticas de Tarea 1 ya borradas.
              Verificar con: show ip route | include ^S
              (no debe devolver nada)

================================================================
  ORDEN DE CONFIGURACIÓN RECOMENDADO
================================================================

  1. R1  → establece la base del Área 1
  2. R3  → conecta Área 0 con Área 1 + configura su lado del VL
  3. R2  → conecta Área 1 con Área 2 + configura su lado del VL
  4. R6  → Área 0 Norte
  5. R7  → Área 0 Sur
  6. R4  → Área 2 Norte
  7. R5  → Área 2 Sur
  8. R8  → ASBR último (distribuye ruta default cuando hay adyacencias)

================================================================


----------------------------------------------------------------
PASO 1 - R1 CENTRAL
Router-ID: 1.1.1.1 | IR | Área 1
Next-hops conocidos: 20.118.216.1 (→R2), 20.118.216.5 (→R3)
----------------------------------------------------------------

enable
configure terminal
hostname R1-Central
router ospf 1
 router-id 1.1.1.1
 network 20.118.224.0 0.0.31.255 area 1
 network 20.118.208.0 0.0.7.255 area 1
 network 20.118.112.0 0.0.15.255 area 1
 network 20.118.216.0 0.0.0.3 area 1
 network 20.118.216.4 0.0.0.3 area 1
 network 20.118.216.24 0.0.0.3 area 1
 passive-interface f0/0
 passive-interface f0/1
 passive-interface f1/0
end
copy running-config startup-config

show ip ospf neighbor


----------------------------------------------------------------
PASO 2 - R3 ALA_OESTE
Router-ID: 3.3.3.3 | ABR | Áreas 0 y 1
Conecta: Área 0 (hacia R6 y R7) + Área 1 (hacia R1)
Virtual-Link: tránsito por Área 1 hacia R2 (2.2.2.2)
Interfaces conocidas: Se0/0 (Área 0→R6), Se0/2 (Área 0→R7), Se0/1 (Área 1→R1)
----------------------------------------------------------------

enable
configure terminal
hostname R3-AlaOeste
router ospf 1

 network 20.118.216.20 0.0.0.3 area 0
 network 20.118.216.4 0.0.0.3 area 1

end
copy running-config startup-config

show ip ospf neighbor
