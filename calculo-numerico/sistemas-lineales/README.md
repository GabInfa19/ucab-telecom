# Sistemas lineales: Gauss, Jacobi y Gauss-Seidel

Foro de **Cálculo Numérico** (UCAB, Ingeniería de Telecomunicaciones).

## Contenido
| Archivo | Descripción |
|---|---|
| `sistemas_lineales.m` | Código en Octave de los problemas 1 y 2 |
| `foro.html` | Desarrollo teórico publicado en el foro (HTML) |

## Problemas
1. **Eliminación de Gauss con pivoteo parcial**, redondeando a 3 dígitos significativos en cada operación.
2. **Métodos iterativos** (Jacobi y Gauss-Seidel) sobre un sistema 3×3 con tolerancia `1e-3`, incluyendo el análisis de convergencia por radio espectral. Gauss-Seidel converge más rápido que Jacobi.

## Ejecutar
Requiere [GNU Octave](https://octave.org/):
```
octave sistemas_lineales.m
```
